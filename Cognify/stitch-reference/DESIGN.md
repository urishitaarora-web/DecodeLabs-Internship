# High performance database for AI applications
## Mission
Create implementation-ready, token-driven UI guidance for High performance database for AI applications that is optimized for consistency, accessibility, and fast delivery across web application.
## Brand
- Product/brand: Cognify
- URL: https://aerospike.com/solutions/use-cases/database-for-ai-applications/
- Audience: registered users and product customers
- Product surface: web application
- Style theme tone: functional, compact, data-dense, and accessible
## Design Token Registry
### Color Tokens
- `color-foreground-1` (Role: foreground): Hex `#000000`
- `color-foreground-2` (Role: foreground): Hex `#1A1A1A`
- `color-background-3` (Role: background): Hex `#FFFFFF`
- `color-accent-primary` (Role: accent): Hex `#F8F413`
- `color-accent-secondary` (Role: secondary): Hex `#0D1B32`
- `color-background-warm` (Role: background): Hex `#F2F1ED`
- `color-background-beige` (Role: background): Hex `#E1DED5`
- `color-muted` (Role: muted): Hex `#8F8F8F`
- `color-border` (Role: border): Hex `#CCC6B7`
### Typography Style Specifications
- Primary Font Family: `Helvetica Now Pro Display`
- Headline Font Family: `Tiempos Headline`

- Typography Scale: `font.size.h1=56px`, `font.size.h2=40px`, `font.size.h3=30px`

### Accessibility Requirements (WCAG 2.2 AA)
- Contrast: Primary text (#000000) on background (#FFFFFF) must be >= 4.5:1.
- Keyboard: All interactive elements must be keyboard-operable.
- Focus Indicators: High-contrast focus indicators required.
- Structure: Semantic HTML (header, nav, main, footer).
