# 📖 About

NovaAI is a responsive AI chatbot designed to deliver a clean and interactive conversational experience through a modern web interface.

The application combines a Flask backend with a premium frontend built using HTML, CSS, and JavaScript. It supports voice input, speech synthesis, emoji insertion, persistent chat history, downloadable conversations, dark mode, and responsive design.

This project demonstrates full-stack web development and deployment using modern web technologies.

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/urishitaarora-web/DecodeLabs-Internship.git
```

### Move into Project

```bash
cd DecodeLabs-Internship
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

Open your browser:

```text
http://127.0.0.1:5000
```
